# nafath-brief
NAFATH-V1

Project Overview

NAFATH-V1 explores how six IT fields can support a secure national login service in Oman.

Six IT Fields

1. Software: OAuth 2.0 and OpenID Connect (OIDC).
2. AI: NIST AI Risk Management Framework.
3. Mobile: Android Runtime Permissions.
4. Networking: DNS over HTTPS (DoH).
5. Cybersecurity: Phishing-resistant authentication.
6. Data: Oman Personal Data Protection Law.

Cybersecurity Focus

The project focuses on protecting citizens’ accounts through phishing-resistant authentication, secure access, privacy protection, and responsible use of AI.
